Overview

Lock Devices Fast and Keep Recovery Moving

When a device goes missing, locking it is just the first step. You also need to locate it, gather network and other information, and get it back. Senturo Lock prevents access to the device, without losing sight of it.

Lock a device directly from your dashboard, or queue the Lock command if the device is offline, ready to deploy when it comes back online. Display return instructions, or trigger the lock automatically through Senturo’s Security Policy Automations. Once you recover the device, use Senturo Unlock to restore access remotely.

Remote lock

Secure a device from the Senturo dashboard to block unauthorized access.

Bulk lock and unlock

Lock and unlock multiple devices at once, instead of handling them individually.

Offline command queueing

Send a lock command even when a device is offline. Senturo queues it and applies it as soon as the device reconnects.

Automation-triggered lock

Add Senturo Lock to Security Policy Automations to lock devices automatically when your predefined conditions are met.

Getting started

How to Lock a Device in Senturo

Once a device is in Missing Mode, secure it directly from its record, or lock several devices at once from your main Devices table.

placeholder · Webflow video
1

Find the device

Open the device from your Senturo dashboard, or choose the devices you want to secure using the Devices table.

2

Select Senturo Lock

Open Security Actions and then select Senturo Lock.

3

Add a recovery message

Write the message and contact details you want to display on the locked device, so whoever has it knows how to return it.

4

Apply Senturo Lock

From your Devices table, select the device, click Security Actions and choose Senturo Lock. If the device is offline, Senturo will queue the Lock command and deploy it as soon as the device comes online.

5

Continue the recovery process

Pull location and network data, send a message, or run other recovery actions as needed.

6

Unlock when recovered

Once the device is back in the right hands, use Senturo Unlock from the dashboard to restore access remotely.
